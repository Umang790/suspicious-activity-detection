# Suspicious Activity Detection Using CNN-LSTM

## Project Overview
A deep learning project to classify video activity as
normal or suspicious, where suspicious means violence-type
physical activity.

## Objectives
- Extract visual features using MobileNetV2.
- Model temporal information using an LSTM.
- Evaluate classification performance.
- Develop a real-time OpenCV application.

## Technology Stack
- Python
- TensorFlow/Keras
- OpenCV
- NumPy
- pandas
- scikit-learn
